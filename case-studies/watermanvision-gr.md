# WatermanVision.gr — coastal camera experience

**Role:** Website development by Stathis Bogris  
**Project:** A TestraTech project  
**Live site:** [watermanvision.gr](https://watermanvision.gr/)

## The product

WatermanVision gives visitors a camera-first view of Anavyssos with coastal conditions and location context. The public site includes an Anavyssos station page, wind and weather information, and a location enquiry flow.

## My work

I built the website's WordPress-based interface and its camera-focused presentation. The design keeps the video prominent and places conditions and beach information nearby so visitors can check the coast before travelling. The private repository contains a theme and a static UI preview from one documented implementation stage.

## Engineering focus

- Responsive layouts for a video-led page and supporting conditions information.
- A clear boundary between the website interface and the separate camera and streaming services.
- Editable website content and an interface that remains useful when a video source is unavailable.
